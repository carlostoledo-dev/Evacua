# Demo script (≈ 2 min 40 s)

Screen-record an iPhone (or Android) with the app **already installed** from
https://evacua-phi.vercel.app (Share → Add to Home Screen) and opened once online, so it is
cached. Voice-over in English (judges); Spanish UI is fine — the subtitles below say what is on
screen. Total target: 2:30–2:50.

## Before recording

- [ ] Phone in **airplane mode** before scene 2 (Wi-Fi off too). Show it in Control Center.
- [ ] Profile: start as **Persona** (adult); have Ajustes ready to switch to **Adulto mayor**.
- [ ] Sound on (voice instructions), Do Not Disturb on, battery > 50 %.
- [ ] Clear the route: Menú → Cambiar ubicación, so the sheet shows "Buscar mi ruta".
- [ ] Location: use the **DEMO** points (we are not in Coronel). They are labeled DEMO on screen.
